# Technical Writing

## About
This repository contains notes as part of the Technical Writing course. It covers different tools and technologies used for creating documents, managing projects, and collaborating effectively.

## Topics Covered

| Topic | Description |
|---|---|
| [LaTeX](./LaTeX/) | Creating structured documents, equations, tables, and bibliographies. |
| [Beamer](./Beamer/) | Creating presentations using LaTeX. |
| [Doxygen](./Doxygen/) | Generating documentation from source code. |
| [Google Docs](./Google%20Docs/) | Creating and collaborating on online documents. |
| [Git](./Git/) | Tracking changes and managing project versions. |
| [GitHub](./GitHub/) | Hosting repositories and collaborating on projects. |

## Objectives
- Learn document creation and formatting tools.
- Understand technical documentation.
- Develop presentation skills.
- Learn version control using Git.
- Understand project hosting and collaboration using GitHub.
